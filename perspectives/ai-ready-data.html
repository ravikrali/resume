There is no AI strategy without a data strategy

Roughly 15% of organisations have data foundations adequate for agentic AI. The other 85% are buying agents and skipping the context they need to be right.

Enterprise AI Architect · Enterprise Data Architect · Director, AI & Data Management Point of view

The requirement this answers

“Ensure enterprise data is AI-ready and fit for GenAI and agentic consumption”

Metadata, lineage, quality, MDM and semantics are not prerequisites you can defer — they are the product.

The constraint is not the model

Frontier models are commodity infrastructure now. What is not commodity is whether your organisation can tell an agent, in machine-readable form, what "active study", "customer" or "revenue" means, who is allowed to see which attribute, and how fresh the answer is.

An agent pointed at an undocumented physical schema does not fail loudly. It produces confident, well-formatted, wrong answers — which is considerably worse.

AI-ready means six specific things

Machine-consumable metadata rather than a wiki with a search box. Column-level lineage that runs end to end. Quality expectations learned from actual distributions, not assertions someone imagined in 2019. Mastered entities so the agent resolves to one customer. A semantic layer where each metric is defined once. And access control inherited from the source, so retrieval cannot leak what the user could not otherwise open.

Permission leakage through vector stores is the single most common security failure I see in enterprise RAG. Documents get embedded; their access control does not come with them.

Sequencing

Build the trust plane before the agent plane. Teams adopt AI authoring roughly three times faster than AI verification — which means shipping defects faster too. If a roadmap places the semantic layer in "a later phase", the roadmap is wrong.

How I apply it

  • Treat the semantic layer and data contracts as Phase 1 deliverables, never Phase 3
  • Govern vector indexes exactly like tables — lineage, classification, retention, access
  • Inherit retrieval permissions from source documents, always
  • Instrument evals on every AI-executed pipeline step

What good looks like

  • Critical metrics are defined once and consumed by BI and agents from the same place
  • The catalog can be queried by a machine at execution time
  • Retrieval quality is measured, not assumed
  • A regulator could be shown how an AI answer was derived
